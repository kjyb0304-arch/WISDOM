# WISDOM – 행정 인허가 선례조사 서비스 페이지

## 포함 파일
- `index.html` : 홈페이지용 서비스 랜딩페이지
- `naver_blog.html` : 네이버 블로그 게시용 완성 HTML
- `service-card-snippet.html` : 기존 홈페이지의 서비스 목록에 삽입할 카드
- `README.md` : 이 파일

## 권장 URL
`/services/administrative-precedent-research/`

## GitHub Pages / 정적 호스팅 배치
1. 이 폴더를 웹사이트 저장소의 `services/administrative-precedent-research/` 경로에 복사합니다.
2. 해당 폴더의 `index.html`이 랜딩페이지가 됩니다.
3. 홈페이지의 서비스 목록 영역에 `service-card-snippet.html` 내용을 붙이고 링크 경로를 실제 배포경로에 맞게 조정합니다.
4. 기존 사이트의 공통 헤더/푸터가 있다면 `index.html`의 독립 헤더·푸터를 기존 컴포넌트로 교체할 수 있습니다.
